CodeDoctor PARTIE BACK-END
est une application web destinée aux développeurs, particulièrement aux débutants
et aux développeurs qui veulent améliorer leur capacité à comprendre et résoudre les erreurs de programmation.
L'idée principale est simple : lorsqu'un développeur rencontre une erreur, l'application ne doit pas seulement lui donner une correction. 
Elle doit surtout lui permettre de comprendre **ce qui s'est passé, pourquoi l'erreur est apparue, comment la diagnostiquer et comment éviter de refaire la même erreur.
